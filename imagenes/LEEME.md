# Fotos del negocio

Pon aquí las fotos originales y ejecuta `npm run images` (también corre solo en `npm run dev` y `npm run build`):

| Archivo | Uso |
|---|---|
| `portada.jpg` | Foto de la portada (si falta, se muestra la ilustración de frascos) |
| `logo.png` | Logo del encabezado y favicon (si falta, se usa la manzana SVG) |
| `mermelada-manzana.jpg` | Mermelada de manzana delicia |
| `mermelada-fresa.jpg` | Mermelada de fresa |
| `mermelada-aguaymanto.jpg` | Mermelada de aguaymanto |
| `duraznos-almibar.jpg` | Duraznos en almíbar |
| `encurtido.jpg` | Encurtido de verduras |
| `caja-regalo.jpg` | Caja de regalo artesanal |

Se convierten a WebP en varios tamaños (portada 640/960/1440 px, productos 400/800 px) dentro de `public/img/`.
