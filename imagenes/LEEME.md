# Fotos del negocio

Pon aquí las fotos originales y ejecuta `npm run images` (también corre solo en `npm run dev` y `npm run build`):

| Archivo | Uso |
|---|---|
| `portada.jpg` | Foto de la portada (si falta, se muestra la ilustración del pie) |
| `logo.png` | Logo del encabezado y favicon (si falta, se usa la manzana SVG) |
| `pie.jpg` | Pie de manzana delicia |
| `torta-canela.jpg` | Torta de manzana y canela |
| `cumple.jpg` | Torta de cumpleaños personalizada |
| `alfajores.jpg` | Alfajores de maicena |
| `empanadas.jpg` | Empanadas de manzana |
| `mermelada.jpg` | Mermelada de manzana |

Se convierten a WebP en varios tamaños (portada 640/960/1440 px, productos 400/800 px) dentro de `public/img/`.
